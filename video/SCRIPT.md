## 1. 카피

`{ }` = 손글씨 강조 · ( ) = 손그림 마크

```
S1  원장님, 아직도 회의 툴로
    {수업}하세요?                      (동그라미)
S2  수업은, 회의가 {아니니까요}.          (밑줄)
S3  온라인에서도
    무대로 {부르고}, 칠판에 {같이 쓰고}, 퀴즈로 {묻고}, 트로피로 {칭찬해요}.
S4  끝난 수업은,
    전부 {기록}이 되고,                (형광펜)
S5  쌓인 기록 덕분에,
    관리는 {클릭 한 번}이면 돼요.        (밑줄)
S6  다 못 보는 수업은,
    {AI가 평가}해 드려요.              (밑줄)
S7  사무실은 이제,
    {선택}이에요.                      (형광펜)
S8  이제 원장님은, {수업}만 보세요.       (동그라미)
S9  회의 말고, {수업}.                  (밑줄)
    ClassIn — 교육을 위해 만든 온라인 교실 · 도입 문의 → [URL]
```

**흐름** — B의 해요체가 처음(질문)·중간(약속)·끝(권유)을 잡고, C의 선언형 연쇄가 가운데를 끌고 갑니다. *끝난 수업은 기록이 되고 → 쌓인 기록 덕분에 관리는 클릭 한 번 → 다 못 보는 수업은 AI가 평가 → 그러니 사무실은 선택.* S1의 "수업하세요?" 동그라미와 S8의 "수업만 보세요" 동그라미가 질문과 답으로 짝을 이룹니다.

## 3. 씬별 구성

### S1 · 질문 `f0–57`
- **카피** `f004` 원장님, 아직도 회의 툴로 · `f022` **{수업}**하세요? (동그라미)
- **화면** 회색 회의 그리드 48칸이 하나씩 켜짐 · 참여도는 평평한 선

### S2 · 전환 `f57–108`
- **카피** `f074` 수업은, 회의가 **{아니니까요}**. (밑줄)
- **화면** `f057` 연두 마커가 그리드를 지움 → 카피 뒤 큰 **음영 아이콘** 회의(카메라, 회색) → '아니니까요'를 다 쓰는 `f093`부터 수업(칠판, 연두 음영)으로 교체

### S3 · 수업 `f108–207`
- **카피** `f110` 온라인에서도 · `f122` 무대로 **{부르고}**, · `f138` 칠판에 **{같이 쓰고}**, · `f154` 퀴즈로 **{묻고}**, · `f170` 트로피로 **{칭찬해요}**.
- **화면** 교실 창: 손든 학생을 강단으로 → 선생님·학생 동시 판서 → 답변기 → 트로피 + 파티클
- **실사 컷** `f186` 실제 수업 화면 — 학생 트로피 **×3**, 학생이 직접 그린 주석(Claire)에 연두 동그라미

### S4 · 기록 `f207–285`
- **카피** `f209` 끝난 수업은, · `f221` 전부 **{기록}**이 되고, (형광펜)
- **화면** '수업 종료' 클릭 → 교실 창이 녹화 카드로 → 녹화·출결·판서·퀴즈·트로피·질문이 수업 기록에 한 줄씩 쌓임
- **실사 컷** `f261` 실제 과정 화면 — 종료된 수업 옆 **녹화·리포트 버튼**에 동그라미, **출석 2/4**에 밑줄

### S5 · 관리 `f285–381`
- **카피** `f287` 쌓인 기록 덕분에, · `f299` 관리는 **{클릭 한 번}**이면 돼요. (밑줄)
- **화면** 데이터가 강사 표로 흘러 들어가 숫자가 채워짐 → 커서가 박서준 강사 클릭 → 강사 카드(수업·출결·AI 평가·녹화 + 최근 수업 기록)
- **실사 컷** `f355` 실제 과정 화면 — **보강-결석자** 반·**채점하기** 버튼에 동그라미, **일일 과제 23/30일**에 밑줄

### S6 · AI 강의 평가 `f381–441`
- **카피** `f383` 다 못 보는 수업은, · `f395` **{AI가 평가}**해 드려요. (밑줄)
- **화면** 사이드바 **에이전트 › AI 평가 NEW** 클릭 → AI 강의 평가 카드(점수 92/100 · 레이더 5축 · 학생 발화 · 상호작용 · 질문 후 대기 · 개선 포인트) · 원장님이 직접 본 수업 0 vs AI가 평가한 수업 48

### S7 · 사무실은 선택 `f441–501`
- **카피** `f443` 사무실은 이제, · `f457` **{선택}**이에요. (형광펜)
- **화면** 사무실 건물이 접혀 사라짐 → **실제 노트북 수업 사진**이 중심 → 서울·대전 강사, 부산·제주·뉴욕 학생이 연두 점선으로 연결

### S8 · 해소 `f501–534`
- **카피** `f503` 이제 원장님은, **{수업}**만 보세요. (동그라미)
- **화면** 48칸이 전부 체크된 대시보드가 뒤에 옅게

### S9 · LOCKUP `f534–600`
- **카피** `f536` 회의 말고, **{수업}**. · `f560` **ClassIn** · `f570` 교육을 위해 만든 온라인 교실 · `f578` 도입 문의 → [URL]
- **화면** 기능 아이콘 14개 궤도 수렴 → 슬로건이 위로 → 연두 링 + 로고 히트
