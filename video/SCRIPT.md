## 1. 스토리

**로그라인** — 회의 화면 속에서 늘 카메라를 끄던 학생이, 진짜 '수업'을 한 번 겪고 다음 날 스스로 카메라를 켠다. 그 사이 원장님은 48개 교실을 한 화면에서 보고, 다 볼 수 없는 수업은 AI가 대신 평가한다.

| 기승전결 | 내용 | 증명하는 기능 |
|---|---|---|
| **기** | 회의 화면 속 민준이는 오늘도 카메라를 껐다 | 문제: 회의용 툴의 한계 |
| **승** | 하지만 오늘은 수업이었다. 무대에 불려 나가고, 칠판에 같이 풀고, 퀴즈 1등, 트로피 | 상호작용 수업 |
| | 밤 11시, 오늘 수업을 한 번 더 봤다 | 자동 녹화 |
| **전** | 같은 시각 원장님은 48개 교실을 한 화면에서 본다. 다 볼 수는 없으니까, AI가 봤다 | 관리자 대시보드 · AI 강의 평가 |
| **결** | 다음 날, 민준이는 카메라를 켰다 → 회의 말고, 수업. | 브랜드 |

시작과 끝이 **같은 구도의 민준 타일**(꺼짐 → 켜짐)이라서, 15초 안에 이야기가 닫힙니다. 장점은 말로 설명하지 않고 *민준이가 바뀌는 것*으로 보여줍니다.

## 2. 내레이션 카피 전문 (읽는 순서)

```
회의 화면 속 민준이는,
오늘도 카메라를 껐다.

하지만 오늘은,
수업이었다.

선생님이 민준이를
무대로 불렀다.
칠판에 같이 풀고, / 퀴즈 1등, / 트로피 하나.
민준이가 웃었다.

밤 11시,
오늘 수업을 한 번 더 봤다.

같은 시각, 원장님은
48개 교실을, 한 화면에서.

다 볼 수는 없으니까,
AI가 봤다.

다음 날,
민준이는 카메라를 켰다.

회의 말고, 수업.
ClassIn
```

> 15초에 담기엔 꽉 찬 밀도입니다(공백 빼고 약 140자). 슬램 라인(굵은 줄)만 읽어도 이야기가 이어지도록 짰고, 나머지는 리듬으로 흘러가요. 같은 스토리를 **30초 버전**으로 늘리면 호흡이 훨씬 자연스러워지니, 매체에 따라 함께 고려해 주세요.
