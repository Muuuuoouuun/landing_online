### BGM · 믹스

- **BGM** `public/music/bed.mp3` — `scripts/make-bgm.py`로 이 영상에 맞춰 만든 오리지널 음원(외부 샘플 없음, 라이선스 걱정 없음). **90 BPM**(1박 = 20프레임), 밝은 마림바 아르페지오 + 플럭 베이스 + 가벼운 킥·클랩·하이햇 + 패드.
  - 0–2.5초(S1 질문): Am 패드와 박자 위 마림바 세 음, 라이저
  - **2.5초(f76, 마커 와이프)**: C 장조로 드롭, 메인 그루브 시작
  - **5.2초(f156, '딱 맞는')**: 벨 화음 강조
  - 7.9–18.5초(S4–S7): 하이햇이 더해져 가장 꽉 찬 구간
  - **장면 경계마다**: 컷 프레임에 정확히 닿는 짧은 역방향 스웰 + 작은 악센트
  - **18.5초(S8)**: 드럼이 빠지는 브레이크다운 + 라이저
  - **21.2초(S9)**: 다시 들어왔다가 한 박 쉬고 → **22.5초(f676 로고 히트)** 큰 C 화음 + 벨 + 크래시, 24초까지 잔향
- **믹스** — '슥슥' 효과음이 날 때 음악이 약 −2.5dB 비켜 줘서(덕킹) 효과음이 음악보다 순간적으로 0–5dB 위. UI 소리(클릭·팝·틱·차임)는 그보다 한 단계 아래. 전체 음량 **−15.9 LUFS**, 트루 피크 **−3.4 dBFS**.
