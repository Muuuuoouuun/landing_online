## 1. 스토리 아크 (한 줄)

> 회색 **회의실** → 와장창 → **교실**로 재조립 → 교실이 살아 움직임 → 끝나면 **자동 녹화** → 카메라가 빠지며 **기관 전체 대시보드** → **AI**가 훑고 평가하고 관리 → 모든 것이 **로고**로 수렴

"이런 게 가능한 이유"는 *교육을 위해 처음부터 설계된 툴이기 때문*이고, 영상은 그걸 말로 설명하지 않고 **기능이 실제로 움직이는 장면**으로 증명합니다. 카피는 주장만 하고, 증거는 UI 모션이 맡습니다.

## 4. 온스크린 카피 전체 (읽는 순서)

```
아직도 / 회의용 툴로 / 수업하세요?
회의 말고, / 수업.
온라인에서도, / 판서하고 / 무대에 올리고 / 퀴즈 내고 / 트로피 주고 / 그룹 나누고 / 교실 그대로.
수업 종료 = 녹화 완료
모든 교실을, / 한 화면에서.
AI가 수업을 평가하고, / 운영까지 관리한다.
회의 말고, 수업. — ClassIn
```

위 메인 카피는 공백·문장부호 빼고 약 100자입니다. 15초 안에 확실히 *읽히는* 건 굵은 슬램 라인(훅 · 회의 말고, 수업. · 수업 종료 = 녹화 완료 · 한 화면에서 · AI 라인)이고, 동사·KPI·태그는 *보이는* 텍스처예요. 쇼릴은 반복 시청을 전제로 하므로 이 밀도가 맞다고 봅니다.
