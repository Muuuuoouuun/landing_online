# ClassIn 15″ — 키네틱 타이포그래피 쇼릴

**대본 v3 · 원장님 시점 · 검토용**

| 항목 | 내용 |
|---|---|
| 길이 / 포맷 | 15초 · 1920×1080(16:9) · 30fps = **450프레임** (9:16 세로 컷다운은 본편 확정 후) |
| 타깃 / 시점 | 온라인 수업을 운영하는 **교육기관 원장님**. 원장님의 속마음이 흘러가듯 쓴 카피 |
| 스토리텔링 | 특정 인물을 따라가는 이야기가 아니라 **카피 흐름 자체가 이야기**: 고민 → 깨달음 → 해법 → 해소 |
| 싱글 메시지 | **"회의 말고, 수업."** |
| 증명 포인트 | ① 실감나는 상호작용 수업 ② 자동 녹화 ③ 기관 관리·관리자 대시보드 ④ AI 강의 평가로 관리 효율 |
| 룩 | **밝은 테마**(오프화이트 종이 + 옅은 격자) · 강조는 **연두 하나** |
| 타이포 | 기본은 Pretendard, **강조 단어만 손글씨**(동해 독도) — 마커로 쓰이듯 등장 |
| 사운드 | **'슥슥' 손글씨 효과음이 주인공**. 음악은 밝고 미니멀하게 뒤에서 받쳐줌(120 BPM) |

**v2 → v3 변경**
- 민준이 캐릭터 서사 삭제 → **원장님 시점의 흐름형 카피**
- 다크 + 코랄 → **밝은 테마 + 연두 강조**
- 강조 = **손글씨 폰트 + 손그림 마크(동그라미·밑줄·체크·형광펜·지우기)**, 쓰는 순간마다 '슥슥'
- 결과물: `out/element-board.png`(스타일 보드), `out/animatic.mp4`(효과음 포함 타이밍 애니매틱)

## 1. 카피 흐름

| 흐름 | 원장님 속마음 | 증명하는 기능 |
|---|---|---|
| **고민** | 회의 툴로 여는 48개의 수업. 정말 수업이었을까? | 문제: 회의용 툴의 한계 |
| **깨달음** | 수업은, 회의가 아니니까. | 회의용 툴 → 교육용 툴 |
| **해법** | 온라인에서도 무대로 부르고, 칠판에 같이 쓰고, 퀴즈로 묻고, 트로피로 칭찬하고. | 상호작용 수업 |
| | 수업 종료 = 녹화 완료 | 자동 녹화 |
| | 48개 교실을, 한 화면에서. | 관리자 대시보드 |
| | 다 볼 수 없는 수업은, AI가 평가한다. | AI 강의 평가 · 관리 효율 |
| **해소** | 이제야, 수업이 보인다. | — |
| **슬로건** | 회의 말고, 수업. ClassIn | 브랜드 |

**카피 장치**
- 첫 줄의 의심 *"정말 **수업**이었을까?"*와 끝의 확신 *"이제야, **수업**이 보인다."*가 같은 단어, 같은 **동그라미**로 짝을 이룸. 인물 없이 카피만으로 이야기가 닫힙니다.
- 원장님이 보고 싶었던 건 '수업'. 그래서 손글씨 강조의 중심 단어도 '수업'.

## 2. 카피 전문

`{ }` = 연두 손글씨 강조 · `( )` = 손그림 마크

```
회의 툴로 여는 48개의 수업.
정말 {수업}(동그라미)이었을까?

수업은, 회의가 {아니니까}(밑줄).

온라인에서도,
무대로 {부르고}, 칠판에 {같이 쓰고}, 퀴즈로 {묻고}, 트로피로 {칭찬하고}.

수업 종료 = {녹화 완료}(체크)

48개 교실을, {한 화면}(형광펜)에서.

다 볼 수 없는 수업은,
{AI가 평가}(밑줄)한다.        AI 강의 평가 {92}(동그라미)

이제야, {수업}(동그라미)이 보인다.

회의 말고, {수업}(밑줄).
ClassIn — 교육을 위해 만든 온라인 교실
```

공백·기호 빼고 로고 줄까지 약 140자. 15초에 꽉 찬 편이라, 한 줄씩 짧게 끊고 강조 단어(손글씨)만 읽어도 흐름이 이어지게 배치했습니다. 체감 속도는 애니매틱으로 확인해 주세요.

## 5. 손글씨 강조 규칙

| 규칙 | 내용 |
|---|---|
| 개수 | **한 줄에 강조 하나.** 강조하지 않는 글자는 전부 기본 폰트 |
| 폰트 | 기본 **Pretendard** / 강조 **동해 독도**(마커 느낌이 가장 강하고 굵어서 연두로도 잘 읽힘). 후보: 나눔손글씨 펜·붓, 개구 — 보드에서 비교 |
| 크기 · 색 | 손글씨는 기본 폰트의 **1.3배**, 글자색 진한 연두 `#5E9E0E` |
| 등장 | 왼쪽부터 잉크가 번지듯 드러남. 쓰는 시간 = 5f + 글자당 2.2f (수업 9f · 녹화 완료 16f) |
| 마크 | 밝은 연두 `#A3E635`, 쓰기 끝나고 2f 뒤. 획 두께 일정 |

**마크 5종의 의미**

| 마크 | 의미 | 쓰는 곳 |
|---|---|---|
| 동그라미 | 이것이 핵심 / 채점 | S1 의심 · S6 점수 · S7 확신 |
| 밑줄 | 단언 | S2 · S6 · S8 |
| 체크 | 완료 | S4 |
| 형광펜 | 한눈에 | S5 |
| 지우기(지그재그) | 버린다 | S2 회의 그리드 |

## 6. '슥슥' 효과음

**방향** — 영상의 리듬은 음악이 아니라 **마커 소리**가 만듭니다. 카피가 쓰일 때마다 '슥슥', 마크를 그을 때 '슥—'. 음악은 밝고 미니멀한 플럭·마림바·가벼운 클랩(120 BPM)으로 뒤에 깔고, 효과음이 날 때마다 음악을 −6dB 덕킹합니다.

**효과음 7종** (`public/sfx/`, `scripts/make-sfx.py`로 생성한 임시본)

| `write-short.wav` | 0.37s | 슥슥 (3획) | 1–3자 손글씨 |
| `write-long.wav` | 0.58s | 슥슥슥슥 (5획) | 4자 이상 손글씨 |
| `circle.wav` | 0.43s | 슥— (한 바퀴) | 동그라미 |
