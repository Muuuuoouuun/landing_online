**대본 v4 · 본편 제작본**

| 항목 | 내용 |
|---|---|
| 길이 / 포맷 | **20초** · 1920×1080(16:9) · 30fps = **600프레임** |
| 결과물 | `out/classin-20s.mp4` (`npm run render`) — 화면 + '슥슥' 효과음 |
| 타깃 / 시점 | 온라인 수업을 운영하는 **교육기관 원장님**. 원장님 속마음이 흘러가는 카피 |
| 싱글 메시지 | **"회의 말고, 수업."** |
| 증명 포인트 | ① 실감나는 상호작용 수업 ② **데이터로 남는다**(자동 녹화 + 수업 기록) ③ **강사·수업 관리가 쉽다** ④ AI 강의 평가 ⑤ **사무실이 필요 없다** |
| 룩 | 밝은 테마(오프화이트 종이 + 옅은 격자) · 강조는 연두 하나 |
| 타이포 | 기본 Pretendard · **손글씨(동해 독도)는 카피의 강조 단어에만**. 숫자·UI·칠판 판서에는 쓰지 않음 |
| 템포 | 15초 → 20초, 100 BPM (1비트 = 18f). 줄마다 읽을 시간이 약 30% 늘어남 |

**v3 → v4 변경**
- 20초로 늘리고 템포를 늦춤
- 장점 3가지 추가: **데이터로 남는다**(S4) · **클릭 한 번으로 강사·수업 관리**(S5) · **사무실 없이도 기관이 돌아간다**(S7)
- 손글씨 폰트 **동해 독도** 확정, 강의 평가 점수 등 숫자에서는 손글씨 제거
- 애니매틱 단계를 넘어 **본편 제작**: 9개 씬 모션 그래픽 + 효과음 믹스

## 1. 카피 흐름

| 흐름 | 카피 | 증명하는 장점 |
|---|---|---|
| **고민** | 회의 툴로 여는 48개의 수업. 정말 **수업**이었을까? | 회의용 툴의 한계 |
| **깨달음** | 수업은, 회의가 **아니니까**. | 회의용 툴 → 교육용 툴 |
| **해법** | 온라인에서도, 무대로 **부르고**, 칠판에 **같이 쓰고**, 퀴즈로 **묻고**, 트로피로 **칭찬하고**. | 상호작용 수업 |
| | 수업이 끝나도, 모든 것이 **데이터**로 남는다. | 자동 녹화 · 수업 기록 |
| | 강사 관리도, 수업 관리도, **클릭 한 번**이면 된다. | 강사·수업 관리 |
| | 다 볼 수 없는 수업은, **AI가 평가**한다. | AI 강의 평가 · 관리 효율 |
| | 사무실 없이도, 기관이 **돌아간다**. | 사무실 불필요 |
| **해소** | 이제야, **수업**이 보인다. | — |
| **슬로건** | 회의 말고, **수업**. ClassIn | 브랜드 |

**연결 고리** — "수업이 끝나도 데이터로 남는다 → 그 데이터 덕분에 관리는 클릭 한 번 → 다 볼 수 없는 건 AI가 평가 → 그러니 사무실이 없어도 된다." 장점이 따로 나열되지 않고 앞의 장점이 다음 장점의 이유가 되도록 이어 붙였습니다. 화면에서도 같은 수업(중2 수학 A반, 박서준 강사)이 S3 → S4 → S5 → S6로 계속 이어집니다.

## 3. 씬별 구성

> `f000` = 등장 프레임(30fps 절대값). `{ }` = 손글씨 강조.

### S1 · 고민 `f0–66`
- **카피** `f006` 회의 툴로 여는 48개의 수업. · `f028` 정말 **{수업}**이었을까? (동그라미)
- **화면** 옅은 회색 회의 화면 48칸이 무작위로 하나씩 켜짐. 전부 같은 크기에 카메라 꺼짐·음소거. 오른쪽 아래 참여도 미터는 평평한 선
- **모션** 슬로 푸시인(1.00 → 1.04) · 카피 뒤 은은한 빛 · 단어가 아래에서 밀려 올라옴

### S2 · 전환 `f66–108`
- **카피** `f076` 수업은, 회의가 **{아니니까}**. (밑줄)
- **화면** `f066` 연두 마커가 지그재그로 회의 화면 전체를 지움 → 그리드가 기울며 접혀 사라지고 배경이 밝은 종이로

### S3 · 수업 `f108–198` — INTERACTIVE CLASSROOM
- **카피** 왼쪽 세로 목록. 새 동사가 오면 앞 줄은 옅어짐
  `f110` 온라인에서도, · `f124` 무대로 **{부르고}**, · `f142` 칠판에 **{같이 쓰고}**, · `f160` 퀴즈로 **{묻고}**, · `f178` 트로피로 **{칭찬하고}**.
- **화면** 오른쪽에 ClassIn 교실 창(강단 6석 · 칠판 · 도구바)
  - 부르고: '서연 손들기' → 커서가 서연을 강단 빈자리로 옮김, 연두 링
  - 같이 쓰고: 선생님(잉크)이 좌표축과 포물선을, 서연(연두)이 꼭짓점에 동그라미를 동시에 그림
  - 묻고: 답변기 팝업, A–D 막대가 올라가고 정답 B 76%
  - 칭찬하고: 트로피가 날아가 서연 자리에 꽂히며 연두 파티클 + 트로피 +1
- **장점 장치** 창 아래 무대·판서·퀴즈·트로피 칩이 동사마다 하나씩 점등. 도구바도 같이 점등

### S4 · 데이터 `f198–276` — AUTO RECORDING · CLASS RECORD
- **카피** `f200` 수업이 끝나도, · `f216` 모든 것이 **{데이터}**로 남는다. (형광펜)
- **화면** 커서가 '수업 종료' 클릭 → 교실 창이 줄어들어 녹화 카드(재생 버튼)가 됨 → 녹화 카드에서 연두 데이터 점이 하나씩 날아가 **수업 기록** 패널을 채움: 수업 녹화 52:10 · 출결 24/24 · 판서 12장 · 퀴즈 정답률 76% · 트로피 9개 · 질문·채팅 31건. 행마다 체크
- **장점 장치** "자동 녹화 · 수업 종료와 동시에 저장" 칩

### S5 · 관리 `f276–366` — TEACHER · CLASS MANAGEMENT
- **카피** `f278` 강사 관리도, 수업 관리도, · `f296` **{클릭 한 번}**이면 된다. (체크)
- **화면** 왼쪽에서 데이터 점이 흘러 들어와 **강사 표**(강사 5명 · 이번 달 수업 · 출결률 · AI 강의 평가 · 수업 추이)의 숫자가 자동으로 채워짐 → 커서가 '박서준'을 클릭 → 오른쪽에 **강사 카드**가 펼쳐짐: 이번 달 수업 38회 · 출결률 99.1% · AI 강의 평가 91 · 녹화·판서 38건 + 최근 수업 기록 3건
- **장점 장치** "수업 기록 1,284건 · 자동 집계" 칩. 데이터가 쌓이니까 관리가 클릭 한 번이라는 인과를 화면으로 보여줌

### S6 · AI 강의 평가 `f366–432`
- **카피** `f368` 다 볼 수 없는 수업은, · `f384` **{AI가 평가}**한다. (밑줄)
- **화면** 스캔 라인이 48칸을 훑으며 칸마다 연두 체크 → **AI 강의 평가 카드**: 점수 92/100(기본 폰트) · 5축 레이더 · 학생 발화 42% · 상호작용 38회 · 질문 후 대기 1.8초 · 개선 포인트
- **장점 장치** 원장님이 직접 본 수업 **0** vs AI가 평가한 수업 **48**

### S7 · 사무실 없이 `f432–498` — NO OFFICE NEEDED
- **카피** `f434` 사무실 없이도, · `f450` 기관이 **{돌아간다}**. (밑줄)
- **화면** '사무실 · 임대 · 출근' 건물이 납작하게 접혀 사라짐 → 노트북 하나에 기관 대시보드(48칸 모두 체크) → 강사(서울 자택·대전) · 학생(부산·제주·뉴욕) · 원장(어디서나)이 연두 점선으로 연결

### S8 · 해소 `f498–534`
- **카피** `f500` 이제야, **{수업}**이 보인다. (동그라미) — S1의 의심 동그라미가 확신의 동그라미로
- **화면** 48칸이 전부 체크된 대시보드가 뒤에 옅게

### S9 · LOCKUP `f534–600`
- **카피** `f536` 회의 말고, **{수업}**. (밑줄) · `f560` **ClassIn** · `f570` 교육을 위해 만든 온라인 교실 · `f578` 도입 문의 → [URL]
- **화면** 영상에 나온 기능 아이콘 14개가 궤도를 돌며 중앙으로 빨려 들어감 → `f560` 연두 링이 퍼지며 로고 히트 → 태그라인 → 연두 CTA 버튼

## 6. 화면 속 정보

- 강사·학생 이름(박서준, 서연 등), 반 이름, 모든 숫자(48개 수업, 출석 24/24, 정답률 76%, AI 강의 평가 92·91, 1,284건 등)는 **화면 연출용 예시**입니다. 실적 수치가 아닙니다.
- **AI 강의 평가 카드 항목**(레이더 5축 · 학생 발화 · 상호작용 · 질문 후 대기 · 개선 포인트)은 실제 결과 화면 항목에 맞춰 교체가 필요합니다.
- 회의 화면은 특정 제품을 떠올리게 하는 로고·아이콘·알림음을 쓰지 않았습니다.
