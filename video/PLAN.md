## 2. 실제 화면 활용 방식 (3안)

| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **① 벡터 재현 + 실사 인서트** (추천) | 모션은 지금처럼 벡터 UI로 하되, **실제 화면 구조를 그대로 옮겨** 재현합니다. 장면 끝에 실사를 0.6–0.8초 프레임 카드로 띄우고 연두 마크로 짚습니다 | 아이콘 모션 유지 · 해상도 문제 없음 · "진짜"라는 증거 | 재현 작업량 |
| ② 실사 화면 중심 | 캡처·사진을 메인 화면으로 쓰고 줌·패닝 + 연두 콜아웃 | 가장 사실적 | 저해상도라 확대 불가 · 모션이 단조로움 · ④⑤의 어두운 톤이 밝은 테마와 충돌 |
| ③ 벡터만 | 실사 없이 벡터 UI만 실제 구조에 맞춰 수정 | 가장 깔끔 | 증명력 약함 |

**실사 처리 규칙** (①안 기준)
- 실사·캡처는 항상 **흰 라운드 프레임**(라운드 22 · 1px 보더 · 그림자)에 넣습니다. 전체 화면에는 쓰지 않습니다(해상도 1098–1391px).
- 표시 크기는 원본 픽셀 이하, 푸시인은 1.1배 이내로 합니다. 클로즈업이 필요한 부분(예: 사이드바 "AI 평가 NEW")은 벡터로 다시 그립니다.
- 짚는 표시는 연두 손그림 마크(동그라미·밑줄)로 합니다. 마크를 그을 때 슥— 소리가 납니다. 손글씨 *글자*는 계속 카피 강조 단어에만 씁니다.
- 실사 컷이 들어오고 나갈 때는 짧은 셔터·클릭 소리를 씁니다.

## 3. S2 음영 아이콘 (시안 2안)

카피 **"수업은, 회의가 아니니까."** 에 회의·수업 아이콘을 붙입니다. 음영은 같은 아이콘을 살짝 어긋나게 한 겹 더 깔아서 만든 그림자입니다. 마커 톤에 맞춘 2도 인쇄 느낌입니다. 시안: `out/sketch-s2-A.png`, `out/sketch-s2-B.png`

| | 시안 A — 좌우 대비 (추천) | 시안 B — 카피 뒤에서 교체 |
|---|---|---|
| 구성 | 왼쪽 **회의**: 영상 카메라 + 사람들 + 서류가방, 회색 음영 · 오른쪽 **수업**: 칠판 + 학사모 + 펜, 연두 음영 · 가운데 ≠ · 아래에 카피 | 카피 뒤에 큰 음영 아이콘 하나. 회의(카메라)가 옆으로 빠지며 작아지고, 수업(칠판)이 연두 음영으로 떠오름 |
| 모션 | 회의 쪽이 먼저 그려졌다가 흐려지며 '회의'에 연두 취소선(슥슥) → 수업 아이콘이 획으로 그려지며 올라옴 → '아니니까' 손글씨 + 밑줄 | 그리드 지우기 직후 회의 아이콘 → `아니니까` 밑줄 순간 수업 아이콘으로 교체 |
| 장점 | 대비가 바로 읽힘 · 아이콘 모션 활용도 높음 · D안 카피와 특히 잘 맞음 | 화면이 단정함 · 카피가 주인공 |
| 주의 | 화면 위아래로 요소가 많아짐 | 큰 아이콘이 카피 가독성을 해치지 않게 농도 40% 이하 |

아이콘: 회의 = `Video` `Users` `Briefcase` (대안 `MessagesSquare` `Handshake`) · 수업 = `Presentation` `GraduationCap` `PenLine` (대안 `School` `BookOpen`)

## 4. 말투 · 카피 대안

`{ }` = 동해 독도 손글씨 강조. 아홉 장면 구조는 그대로입니다.

### A. 원장님 혼잣말 — 현재 (140자)
담담하고 공감형입니다. 원장님 마음속 목소리를 그대로 옮깁니다.
```
S1 회의 툴로 여는 48개의 수업. / 정말 {수업}이었을까?
S2 수업은, 회의가 {아니니까}.
S3 온라인에서도, 무대로 {부르고}, 칠판에 {같이 쓰고}, 퀴즈로 {묻고}, 트로피로 {칭찬하고}.
S4 수업이 끝나도, 모든 것이 {데이터}로 남는다.
S5 강사 관리도, 수업 관리도, {클릭 한 번}이면 된다.
S6 다 볼 수 없는 수업은, {AI가 평가}한다.
S7 사무실 없이도, 기관이 {돌아간다}.
S8 이제야, {수업}이 보인다.
S9 회의 말고, {수업}.
```

### B. 원장님께 건네는 말 — 해요체 (139자)
상담하듯 다정합니다. 원장님 대상 퍼포먼스 광고·영업 자료용으로 좋습니다.
```
S1 원장님, 아직도 회의 툴로 / {수업}하세요?
S2 수업은 회의와 {달라야} 하니까요.
S3 온라인에서도 무대로 {부르고}, 칠판에 {같이 쓰고}, 퀴즈로 {묻고}, 트로피로 {칭찬해요}.
S4 수업이 끝나면, 전부 {데이터}로 남아요.
S5 그 데이터로 강사도 수업도, {한눈에} 관리하고요.
S6 다 못 보는 수업은, {AI가 평가}해 드려요.
S7 사무실이 없어도 {괜찮아요}.
S8 이제 원장님은, {수업}만 보세요.
S9 회의 말고, {수업}.
```

### C. 선언형 연쇄 — 매니페스토 (101자) · 추천
짧고 단정합니다. 글자가 커지고 모션 여백이 생겨 시네마틱 쇼릴에 가장 맞습니다. "끝난 수업 → 기록 → 관리 → AI"가 한 문장처럼 이어집니다.
```
S1 오늘도 48개의 수업이 열렸다. / 아니, 48개의 {회의}가.
S2 수업은, 회의가 {아니다}.
S3 온라인에서도, {부르고}. {쓰고}. {묻고}. {칭찬하고}.
S4 끝난 수업은, {기록}이 되고
S5 쌓인 기록은, {관리}가 된다.
S6 다 못 본 수업은, {AI}가 본다.
S7 그러니 사무실은, {선택}.
S8 남는 건 오직, {수업}.
S9 회의 말고, {수업}.
```

### D. 비포 · 애프터 대구 (109자)
회의 툴과 ClassIn을 한 줄씩 맞세웁니다. 차이가 가장 선명하고, S2 시안 A(좌우 대비)와 짝이 좋습니다.
```
S1 회의 툴에선, 48개의 {화면}.
S2 ClassIn에선, 48개의 {교실}.
S3 화면 공유 대신 {같이 쓰고}, 리액션 대신 {묻고}, 박수 대신 {트로피}.
S4 끝나면 사라지던 수업이, {데이터}로.
S5 엑셀로 하던 관리가, {클릭 한 번}으로.
S6 감으로 하던 평가가, {AI}로.
S7 사무실이 하던 일을, {노트북 하나}가.
S9 회의 말고, {수업}.
```
D는 S8(해소)을 빼고 그 시간을 S3–S7에 나눠 씁니다. "리액션·박수"는 특정 제품명 없이 일반적인 회의 툴 기능을 가리키는 표현입니다.
