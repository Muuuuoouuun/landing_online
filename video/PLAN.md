## 2. 해법 요약

1. **24초 · 90 BPM** — 1마디 = 80프레임(2.67초), 24초 = 정확히 9마디. 장면 수는 그대로 두고 장면당 시간을 늘립니다.
2. **솔루션 선언 장면 신설 (S3)** — 3초 무렵에 *"ClassIn은, 온라인 수업에 딱 맞는 교실이에요."* 영상의 나머지를 "그 증거"로 읽히게 합니다.
3. **'온라인 수업 체크리스트' 바** — S3에서 빈 칸 5개로 등장하고, 장면마다 하나씩 연두 체크가 켜집니다. 엔딩에서 5/5가 되며 로고로 모입니다. "딱 맞는"을 눈으로 증명하면서, 장면 사이를 잇는 다리 역할도 합니다.
4. **페이드 없는 전환** — 빈 화면 깜빡임을 없애고, 앞 장면의 요소가 다음 장면의 요소로 변하는 매치 컷·모프·카메라 이동으로 잇습니다.
5. **템포 규칙** — 메인 카피는 다 쓰인 뒤 최소 1.2초 유지, 손글씨·마크는 약 1.4배 느리게, 실사 컷 1초 안팎.

## 5. 컷 전환 설계

**원칙** — ① 빈 화면으로 빠지는 페이드 금지 ② 앞 장면의 요소가 다음 장면의 요소가 된다 ③ 카메라 이동 방향은 계속 오른쪽(시간이 흐르는 방향) ④ 전환은 박자 위에, 음악 악센트와 함께.

| 전환 | 프레임 | 방식 | 설명 |
|---|---|---|---|
| S1 → S2 | f76 | **마커 와이프** (유지) | 연두 지그재그가 회의 그리드를 지움 + 음악 드롭 |
| S2 → S3 | f136 | **아이콘 모프** | 카피 뒤 연두 음영 칠판 아이콘이 앞으로 나오며 커지고, 선으로 그린 **ClassIn 교실 창 윤곽**으로 변함. 그 옆에 ClassIn 워드마크가 처음 등장 |
| S3 → S4 | f210 | **선 → 실체 (무컷)** | 선으로만 그려졌던 교실 창이 같은 자리에서 실제 UI로 채워짐(좌석·칠판·도구바). 카피는 위로 밀려 올라가며 교체 |
| S4 안 | f300 | **매치 컷** | 벡터 교실 창 위로 **같은 위치·같은 크기**의 실제 수업 화면이 0.3초 크로스페이드 → "이게 진짜 화면" |
| S4 → S5 | f334 | **클릭 → 축소 (무컷)** | '수업 종료' 클릭 → 교실 창이 녹화 카드로 줄어들며 왼쪽으로 (v5 방식 유지) |
| S5 → S6 | f418 | **카메라 팬** | 화면 전체가 왼쪽으로 흘러가며(넓은 대시보드를 훑는 느낌) 수업 기록 패널이 강사 표의 한 행으로 들어감. 연두 데이터 점이 동선을 이어줌 |
| S6 → S7 | f504 | **공유 요소 줌** | 강사 카드의 'AI 강의 평가 91' 타일을 클릭 → 그 타일이 커지며 AI 강의 평가 카드가 됨 |
| S7 → S8 | f576 | **줌 아웃 매치 컷** | 평가 카드·대시보드 전체가 작아지며 **노트북 사진의 화면 속으로** 들어감 → 사진이 중심, 지역 핀이 연결 |
| S8 → S9 | f640 | **수렴** | 핀·연결선·체크리스트 5칸이 중앙으로 모여 ClassIn 로고가 됨 |

**카피 전환** — 장면 안에서 카피 위치를 고정하고, 새 줄이 아래에서 올라오면 이전 줄은 위로 밀려나며 흐려집니다(스크롤형). 장면마다 같은 자리에 '뚝' 새로 뜨는 반복감을 없앱니다.

**실사 컷** — 갑자기 튀어나오는 팝업 대신, 화면 속 같은 요소에서 이어지게 합니다. S4는 벡터 창 → 실제 화면 매치 컷. S5·S6은 짚을 버튼(녹화·리포트, 채점하기)을 벡터 화면에서 먼저 동그라미 치고, 같은 버튼이 실사 화면에서 다시 동그라미 쳐지는 순서로 연결합니다.

## 6. "온라인 수업에 딱 맞는" 강조 장치

| 장치 | 위치 | 역할 |
|---|---|---|
| **솔루션 선언 장면** | S3 (4.5–7.0초) | ClassIn을 "온라인 수업용 교실"로 정의. 브랜드를 초반에 한 번 각인 |
| **온라인 수업 체크리스트 바** | S3 등장 → S4–S8 하나씩 체크 → S9 5/5 | 영상 전체를 "필요한 것 5가지를 다 갖췄다"는 증명으로 묶음 |
| **엔딩 태그라인** | S9 | "온라인 수업에 딱 맞는 교실" — 선언과 같은 문장으로 수미상관 |
| **장면 라벨 통일** | 각 장면 좌상단 | 영문 라벨 대신 체크리스트 항목명과 같은 한국어 라벨 (예: "실시간 상호작용") |

체크리스트 바 디자인 — 하단 중앙, 흰 알약 모양 칩 5개. 빈 칸은 회색 테두리, 증명되면 연두 배경 + 체크가 그려집니다(슥 소리는 넣지 않고 작은 틱만). 엔딩에서 5칸이 한 줄로 모였다가 로고 아래 "온라인 수업에 딱 맞는 교실" 한 줄로 바뀝니다.

## 8. 사운드

- **BGM 재작곡** — 90 BPM, 24초. 장면 전환을 전부 박자 위(20프레임 간격)에 놓고, 컷마다 컷 프레임에 닿는 짧은 스웰을 넣습니다. S2 마커 와이프에서 드롭, S3 선언에서 첫 화음 강조, S8 사무실에서 드럼이 빠지는 브레이크다운, S9 로고에서 마지막 다운비트 후 24초까지 잔향.
- **전환 효과음** — 카메라 팬에는 부드러운 스우시, 줌 아웃에는 낮은 스웰, 매치 컷에는 셔터 클릭 1번. 체크리스트 점등은 작은 틱.
- **'슥슥'** — v5 믹스 비율 유지(음악보다 0–5dB 위). 손글씨가 느려진 만큼 쓰기 효과음도 길이를 맞춰 다시 만듭니다.
